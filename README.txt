PHONE SIMULATOR - Android project

How to build APK using GitHub:
1. Upload the CONTENTS of this folder to your GitHub repository (main branch).
2. Open the repository Actions tab.
3. Select "Build Android APK" and press "Run workflow" (or wait for the automatic build after upload).
4. When the run finishes, open it and download the artifact named "PhoneSimulator-debug-apk".
5. Extract the ZIP artifact and install app-debug.apk on your Android phone.

This is an early WebView-based Android wrapper around the included game prototype.
